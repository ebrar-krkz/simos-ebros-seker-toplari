# 🍬 Simos ve Ebros'un Şeker Topları

Pastel tonlarda tasarlanmış, çarpışma fiziğine sahip, ses efektli interaktif şeker topu animasyonu.  
Bu proje HTML, CSS ve JavaScript kullanılarak geliştirilmiş, eğlenceli ve görsel açıdan hoş bir canvas uygulamasıdır.

Toplar duvarlara ve birbirlerine çarparken fiziksel olarak doğru şekilde hareket eder, fade-trail efekti sayesinde arkasında hoş bir iz bırakır ve kullanıcı farklı boyutlarda, farklı renklerde yeni toplar ekleyebilir.

---

## 🎀 Proje Açıklaması

Bu uygulama tamamen *vanilla JavaScript* ile yazılmıştır ve aşağıdaki özellikleri içerir:

- Kullanıcının istediği boyutta ve renkte şeker topları ekleme
- Topların birbirleriyle **elastik çarpışma fiziği**
- Canvas üzerinde **yumuşak fade trail efekti**
- **Ses efektleri** (aç/kapa)
- **Hız artırma mekaniği**
- Başlat / durdur / sıfırla kontrolleri
- Klavye kısayolları desteği

Uygulama tamamen responsive çalışır ve pastel temalı, yumuşak görünüm için tasarlanmıştır.

## 🎮 Kullanım

1. Proje klasörünü indir.
2. `index.html` dosyasını herhangi bir tarayıcıda aç.
3. Arayüz üzerinden şu işlemleri gerçekleştirebilirsin:

- Boyut seç  
- Renk seç  
- Top ekle  
- Hızlandır  
- Ses aç/kapa  
- Başlat / Durdur / Sıfırla  

Ekranın sağ üst köşesinde:

- Top sayısı  
- Güncel hız katsayısı  

canlı olarak gösterilir.

## 🧪 Testler

Projede yer alan `test-sugar-balls.js` dosyası, sayfa yüklendiğinde tarayıcı konsolunda otomatik testler çalıştırır.

Bu testler:

- Butonların varlığını kontrol eder  
- Sayaçların doğru güncellenip güncellenmediğine bakar  
- Hız artırma fonksiyonunu doğrular  
- Ses butonunun aç/kapa değişimini sınar  
- Reset fonksiyonunun çalışmasını test eder  

Tüm sonuçlar konsolda listelenir.
